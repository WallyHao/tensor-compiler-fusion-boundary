# E · 标签、模型与单卡交付

**输入**　通过 D 的正式 3090 Ti 配对数据。以下口径在正式采集前连同配置表锁定。改变口径的探索分析另记版本和原因。

## 收益与不确定性

对每个 case/mode，从每个有效 block 得到 sᵢ、fᵢ（µs/call）。T_split、T_fused 分别取 30 个块的算术平均，B = mean(sᵢ − fᵢ)，相对收益为 B/T_split。另报各自中位数和 IQR。用种子 2026 对 30 个**整对**有放回抽样 10000 次，每次重算 B 和相对收益，以 2.5%、97.5% 分位数作区间。解释为本次稳态运行的重复测量不确定性；新进程复跑另列。

预设实际意义带 ±2%（课程研究约定），相对收益区间整体高于 +2% 标为 fuse，整体低于 −2% 标为 split，整体落在带内标为 equivalent，跨带边界标为 uncertain。另给 ±1% 和 ±5% 的敏感性表。按模板、dtype 作图：逐元素类横轴 N；归约类横轴 K、纵轴 M，色值为 B/T_split。区分未成对、近似等价和未判定。只在已测相邻尺寸间标注有证据的符号翻转。

## 决策预算与特征

主模型用于普通启动。允许先编译两个候选、读取静态资源并测 split；生成模型输入表时采用字段白名单。fused 计时、两者实测差、运行后 occupancy、实测 DRAM 流量、由实测选择的最佳 kernel 均属标签或诊断。若调优过程计时了完整候选，应关闭该路径或单列受影响样本并披露测量预算。

| 输入（均以 µs 表示） | 从原始行计算 |
|---|---|
| x₁，启动 | (split 静态发射数 − fused 静态发射数) × 普通启动校准 L；用编译产物统计，另用 trace 验证映射 |
| x₂，传输 | 消除的 t 逻辑写入与读取字节数 / 大尺寸校准 BW；它是名义传输时间 |
| x₃，资源 | T_split × (o_split − o_fused)。对受切边影响的各 kernel，由编译得到的 block 大小、寄存器、shared memory 和目标设备限制，通过 CUDA occupancy API 取得每 SM 可驻留 block 数；乘每 block 的 warp 数再除以每 SM 最大 warp 数得到静态驻留比例 o。每个策略取该区域各 kernel 的最小 o，记录逐 kernel 输入、函数句柄来源和聚合值 |

x₃ 是待检验的粗略代理，小 grid 可能无法达到该驻留比例。资源缺失保留 null。先拟合两项模型 B̂ = a·x₁ + b·x₂，再在资源齐全子集拟合 B̂ = a·x₁ + b·x₂ − c·x₃，普通最小二乘、无截距。两模型在同一完整子集再比较一次。报告系数、矩阵秩和条件数；秩亏时仅报告预测与不可辨识性。模型预测 B̂ > 0 选择 fused，否则 split。replay 单独报告观测收益，避免混用启动常数。样本不足以估计某折时标为 unavailable。

## 验证与基线

- 采用四折 leave-one-template-out。每次留出一个完整模板，在其余模板可用行上拟合系数及阈值，保存逐折训练和测试 ID。所有 shape、dtype、重复运行跟随模板分组。主模型为两项，三项为预设扩展；报告各折样本数和模板宏平均。只有四个模板，外推范围限于所列子图类型。
- 比较始终融合、始终切分、固定配置下 Inductor 的实际选择，以及独立规则“逻辑节省字节数 > τ”。在训练折枚举不同字节数的相邻中点和两端的恒选规则，取平均绝对决策损失最小的 τ；并列取较大 τ。对同分异号案例给出参数、区间和证据，可据此讨论该字节阈值的上限。
- 主要决策指标为 regret = T_chosen − min(T_split,T_fused)，单位 µs/call，同时报告 regret/min(T_split,T_fused)。所有有效配对均进入损失统计，按模板给均值和最大损失。只在 fuse/split 明确的点报符号准确率和逐类计数，注明其占全部有效点的比例。默认策略比较限于可映射的同一组 ID，所有方法同时报告实际覆盖率。
- 若所有点只出现一种可靠符号，报告恒选基线与可改善空间；形状间的有效样本不能支持另一侧边界时注明缺口。选取每类至少一个代表案例，额外展示默认策略最大损失点和模型最大损失点；保存选择规则，区分预选诊断点与事后选例。
