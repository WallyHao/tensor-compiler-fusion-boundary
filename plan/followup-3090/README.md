# RTX 3090 局部融合边界补采

在自有 **RTX 3090** 上检验长归约、输入步长和模型片段中是否出现拆分获益、默认策略错选或候选无法配对。原网格在 RTX 3090 和 RTX 4090 上各测了 72 个配置，H800 PCIe 测了其中 12 个。本轮采集范围为 16 个新配置和 4 个原配置同期对照。[完整项目计划](../../docs/research-plan.md)

| 顺序 | 工作单 | 完成后交付 |
|---|---|---|
| 1 | [语料与候选](01-candidates.md) | 机器可读配置、可复跑入口、切边和正确性证据 |
| 2 | [采集与复跑](02-collection.md) | 环境、试点、校准、正式配对原始行及诊断 |
| 3 | [审计与交付](03-analysis.md) | 覆盖表、收益图、复跑和可校验归档 |

[cases.csv](cases.csv) 是执行清单。每行都有最终状态，包含无法构造候选或无法完成测量的行。默认起点是仓库中归档的 RTX 3090 软件栈和设备 UUID。连接主机后可直接在本机终端或已有 SSH 会话运行。实验写入持久盘，编译、校准、预测、正式计时及 profiler 串行独占 GPU。

> 交给主机执行者：从本提交创建工作分支，按三个工作单执行补采。提交代码、实际命令及交付摘要，保留带 SHA-256 的原始证据包。完成时回传分支或 commit、归档路径、按组和模式的有效配置数，以及一个可追溯实例。实验期间使用本机 RTX 3090。
